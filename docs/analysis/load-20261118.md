# Nexmark Q8 offered rate — 18 November 2026

Status: **PARTIAL**. Five events/second and 25 events/second each have three accepted repetitions of all five policies. Eighty events/second has one repetition of Vanilla, Faa$T, Cloudburst, and Pheromone. STateFlow at 80 events/second did not finish: the orchestrator closed the connection. The occupancy sweep and the expiry diagnostic were not run.

Event time stays at five semantic events per second per namespace. Wall-clock release is a separate exponential clock. The k-th event is the same object at every offered rate. A 60-second measurement still covers only minutes of the 12-hour window, not expiry. Published objects at 5/s average about 18 KB. This is not a 2.2 MB workload.

The image is the coherent build `docker.io/dcchico/nexmark-q8:beam-q8-coherent-20261115`, manifest `sha256:7128537c…`. It was not rebuilt. The five-policy gate was 180 measured joins each, zero mismatches. STateFlow was direct. Vanilla was redis-object.
